개인정보 처리방침

"식단 기록"(이하 "앱")은 식단·체중·활동을 기록하는 앱입니다. 앱에는 회원가입이 없고, 운영자가 따로 운영하는 서버도 없습니다. 이 방침은 앱이 어떤 정보를 어디에 저장하고 어디로 보내는지 설명합니다.

시행일: 2026년 11월 5일

1. 휴대폰 안에만 저장하는 정보

다음 정보는 사용하는 휴대폰(또는 브라우저) 안에만 저장되며 운영자에게 전송되지 않습니다.

  • 식단 기록, 즐겨찾기·세트, 메모
  • 목표(성별·나이·키·활동량·목표 체중 등)와 목표 변경 기록, 치팅데이
  • 체중·체지방·골격근량 등 체성분 기록
  • 물·영양제 체크
  • 사용자가 입력한 Gemini API 키

2. 건강 데이터

사용자가 허용한 경우에만 아이폰 건강 앱(HealthKit) 또는 안드로이드 Health Connect에서 다음 정보를 읽기만 합니다.

  • 걸음 수, 활동 칼로리, 운동 기록
  • 체중, 체지방률

읽은 데이터는 활동 화면 표시와 하루 목표 영양성분 계산에만 쓰고, 휴대폰 안에만 저장합니다. 외부로 보내거나 광고에 쓰지 않으며, 건강 앱에 데이터를 쓰지 않습니다.

3. AI 기능 (Google Gemini)

사용자가 직접 발급한 Gemini API 키를 입력하고 AI 기능을 쓸 때만, 그 요청에 필요한 내용이 사용자의 키로 Google Gemini API에 직접 전송됩니다. 운영자를 거치지 않습니다.

  • AI 검색: 입력한 음식·메뉴 이름과 질문
  • 재료 입력: 입력한 재료 목록과 양
  • 사진으로: 음식 사진 또는 영양성분표 사진, 사용자가 적은 설명
  • 인바디: 인바디 결과지 사진

사진은 보내기 전에 휴대폰에서 크기를 줄이고 다시 저장하므로 위치 등 사진 정보(EXIF)는 빠집니다. Gemini는 답을 찾기 위해 Google 검색을 사용할 수 있습니다. 전송된 내용은 Google의 약관과 개인정보처리방침에 따라 처리되며, 무료 키의 경우 Google이 서비스 개선에 사용할 수 있습니다. 자세한 내용은 Gemini API 약관을 확인해 주세요. 건강 앱에서 읽은 데이터는 전송하지 않습니다.

4. 그룹 공유 (Google Firebase)

사용자가 그룹 기능을 켜고 그룹에 참여한 경우에만, 다음 정보가 Google Firebase(Cloud Firestore)에 저장되어 같은 그룹 멤버에게만 보입니다.

  • 익명 로그인 식별값(이름·이메일·전화번호 등은 받지 않음)
  • 닉네임, 프로필 사진(설정한 경우), 목표 이름(예: 컷팅)
  • 최근 식단(끼니별 음식 이름·재료 이름·칼로리·탄단지, 끼니 평가)과 하루 목표 영양성분
  • 주간 한줄평과 메모, 멤버가 남긴 댓글

그룹에서 나가면 그 그룹에 올린 내 식단·주간 기록과 닉네임·사진이 삭제됩니다. 내가 다른 사람 기록에 남긴 댓글은 남을 수 있으며, 직접 지울 수 있습니다.

5. 음식 공유 링크

음식을 공유하면 음식 이름과 영양성분이 링크 주소 안에 담깁니다. 링크를 받은 사람은 그 내용을 볼 수 있습니다.

6. 보관과 삭제

휴대폰 안의 기록은 앱을 삭제하거나 브라우저 데이터를 지우면 함께 삭제됩니다. 설정의 백업 기능으로 저장한 파일은 사용자가 직접 관리합니다(Gemini API 키는 백업 파일에 넣지 않습니다). 그룹에 올린 정보는 그룹에서 나가면 삭제됩니다. 건강 데이터 접근 권한은 건강 앱 또는 Health Connect 설정에서 언제든 끌 수 있습니다.

7. 만 14세 미만

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

8. 영양정보 안내

앱의 영양정보(식약처 식품영양성분 DB, AI 검색·추정 값 등)는 참고용이며 실제와 다를 수 있습니다. 앱의 목표 칼로리·조정 제안은 의료 조언이 아닙니다.
